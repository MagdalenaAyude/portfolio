# Portfolio Profesional — Magdalena Daniela Ayude 🚀

Este es mi portfolio personal como **Desarrolladora Frontend Jr**. Un espacio diseñado bajo una estética minimalista y profesional para dar a conocer mis proyectos, habilidades y enfoque de desarrollo.

---

## 🛠️ Tecnologías y Herramientas

El proyecto fue desarrollado desde cero, priorizando un código limpio, estructurado y altamente eficiente:

* **HTML5:** Estructura 100% semántica, optimización SEO técnica y accesibilidad web.
* **CSS3:** Maquetación moderna con CSS Grid y Flexbox, variables globales (`:root`), tipografía fluida (`clamp()`) y diseño asimétrico.
* **Diseño Responsive:** Adaptabilidad completa para celulares, tablets y monitores grandes mediante Media Queries.
